#  My Learning Philosophy

I don't aim to memorize solutions.

For every problem I solve, I focus on:

1. Understanding the problem.
2. Thinking about different approaches.
3. Learning from mistakes.
4. Writing the optimized solution.
5. Understanding why the solution works.
6. Revisiting difficult problems.
